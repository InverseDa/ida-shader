# IDA Shader

一款为 Minecraft Java 版制作的光影包，在保留方块世界风格的同时，丰富光照、天空、水面和天气表现。

## 主要效果

- **光照与阴影**：日月光照、柔和阴影、植被透光，以及火把、灯笼等光源的照明与阴影。
- **天空与云雾**：方块体积云与真实体积云两种风格，搭配地表云影、雾气和阳光光束。
- **水面与水下**：随群系变化的水色、流动波纹、轻微起伏、倒影与折射，以及浅水焦散和水下光束。
- **雨天氛围**：地表逐渐湿润，露天区域出现局部积水倒影，雨停后缓慢干燥。
- **画面调节**：泛光、曝光、色彩和抗锯齿设置，支持原版材质与基础 LabPBR 资源包。

## 安装

当前开发与测试环境为 **Minecraft Java 1.21.4 + Fabric + Iris 1.8.8**，显卡和驱动需要支持 **OpenGL 4.3**。目前主要适配主世界，其他版本和维度尚未完整验证。

1. 安装与游戏版本匹配的 Fabric 和 Iris。
2. 将光影包 ZIP 或 `ida-shader` 文件夹放入当前游戏实例的 `shaderpacks` 文件夹。包内应直接包含 `shaders` 文件夹，避免多套一层目录。
3. 在游戏的视频设置中打开光影包菜单，选择 **IDA Shader** 并应用。

无需额外资源包即可使用。搭配 LabPBR 资源包时，在光影设置的「材质 → 材质格式」中选择 **LabPBR**。

## 常用设置

可以先使用默认配置，再按喜好调整：

| 想调整的效果 | 设置位置 |
| --- | --- |
| 云的外观 | 云与植被透光 → 云风格 |
| 水面波纹与起伏 | 水面与水下 → 水面波纹强度 / 轻微水面起伏 |
| 阳光光束 | 体积光 → 阳光光束 / 光束强度 |
| 火把、灯笼等照明 | 光照基准 → 局部光源 |
| 雨天地面与倒影 | 天气与湿润 |
| 画面亮度和色彩 | 曝光与颜色 |

帧率不足时，可尝试降低真实云精度、光束精度，或关闭局部光源阴影、近场体素 GI 和积水倒影。实际开销随分辨率与场景变化。

## 当前状态

项目仍在持续调整画质与性能。水面在近岸移动、树叶密集等场景中仍可能出现倒影缺口或闪烁；屏幕外的地形也无法完整呈现在水面倒影中。LabPBR 目前仅支持部分材质效果。
